# Cognitive Load & Memory Ergonomics

---

## 1. Overview

Cognitive Load Theory divides mental processing into Intrinsic, Extraneous, and Germane load. Tier-1 applications ruthlessly eliminate **extraneous load** (cluttered UI, ambiguous icons, missing inline validation).

---

## 2. Recognition vs Recall

- **Recall (High Friction)**: Memory retrieval without prompts (e.g. typing raw terminal flags).
- **Recognition (Low Friction)**: Visual autocomplete, icon-plus-label buttons, search history pill chips.
