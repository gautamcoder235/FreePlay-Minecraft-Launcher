# Laws of UX (Hick's, Fitts's, Jakob's, Miller's)

---

## 1. Overview

Psychological principles govern human-computer interaction. Tier-1 applications leverage these laws to minimize friction and elevate user velocity.

---

## 2. The Core Laws of UX Summary

### Hick's Law ($T = b \cdot \log_2(n + 1)$)
Decision time increases logarithmically with the number ($n$) of options. Command palettes (`Cmd+K`) convert $O(n)$ menu parsing into $O(\log n)$ fuzzy search.

### Fitts's Law ($MT = a + b \cdot \log_2\left(\frac{2D}{W}\right)$)
Movement time decreases as target width ($W$) increases or distance ($D$) decreases. Pinned screen edges have infinite target width on desktop OS displays.

### Jakob's Law
Users prefer your application to operate similarly to tools they already master (familiar hotkeys, standard treeview navigation).

### Miller's Law ($7 \pm 2$)
The human working memory holds only $7 \pm 2$ items simultaneously. Group complex sidebar navigation into distinct sections of 5–7 items.
