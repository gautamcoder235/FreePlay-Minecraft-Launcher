# Apple HIG vs Material 3 vs Fluent 2

---

## 1. Overview

Comparing major industry design frameworks (Apple HIG, Google Material 3, Microsoft Fluent 2) illuminates structural trade-offs across motion physics, surface elevation models, color token architectures, and platform ergonomics.

---

## 2. Comparative Design System Matrix

| Metric / Dimension | Apple HIG | Material Design 3 (M3) | Fluent 2 (Microsoft) |
| :--- | :--- | :--- | :--- |
| **Core Philosophy** | Tactile realism, spatial depth, translucent materials | Expressive dynamic color (Monet), tonal palettes | Seamless productivity, soft depth, rounded geometry |
| **Color Model** | Dynamic System Colors & Materials | 5-Tier Tonal Palette System | Global -> Alias -> Component Tokens |
| **Motion Physics** | Fluid Spring Dynamics (`CASpringAnimation`) | Material Easing (Emphasized, Standard) | Fluent Motion Curves |
| **Primary Platform** | macOS, iOS, iPadOS, visionOS | Android, Web, Flutter | Windows, Web, React Native |
