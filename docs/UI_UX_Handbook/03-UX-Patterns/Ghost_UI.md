# Ghost UI & Placeholders

---

## 1. Overview

Ghost UI elements present faint outline shapes of inline controls (inputs, user avatars, status tags) while background state hydration completes.

---

## 2. Ghost UI Specification

```css
.ghost-avatar {
  width: 32px;
  height: 32px;
  border-radius: 50%;
  background: var(--bg-surface-hover);
  opacity: 0.6;
}
```
