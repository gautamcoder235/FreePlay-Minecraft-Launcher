# Security Policy

## Supported Versions

We release security updates and bug fixes for the current release channel of FreePlay:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

The FreePlay team takes security issues seriously. If you discover a security vulnerability in FreePlay, please follow these steps:

1. **Do NOT disclose the issue publicly** in an open GitHub issue, forum, or social media.
2. **Report Privately**: Please submit a private security advisory via GitHub Security Advisories at:
   [https://github.com/gautamcoder235/FreePlay-Minecraft-Launcher/security/advisories/new](https://github.com/gautamcoder235/FreePlay-Minecraft-Launcher/security/advisories/new)
   or reach out directly to the maintainer.

### What to include in your report:
- A clear description of the vulnerability.
- Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
- The affected component (e.g., Desktop shell, launcher core, server supervisor, web interface).
- Any proposed remediation or patch if available.

### What to expect:
- **Acknowledgement**: We aim to acknowledge receipt of your report within 48 hours.
- **Assessment**: We will evaluate the vulnerability and provide updates as a fix is developed.
- **Credit**: We will credit reporters in the release notes upon public disclosure unless you prefer to remain anonymous.
